# dev-flow-lite：四步研发编排

对 PRD 路径、当前目录中的 PRD 或对话需求执行轻量流程。默认中文交流，不写流程文档、不保存恢复状态；仅在用户明确传入 `--overview` 时维护 `总览.md`。

1. 使用 `read-prd` 技能读取资料并输出需求摘要，请用户确认。
2. 使用 `grill` 技能消除影响实现的歧义：一次一个问题，先查代码，再给建议答案。
3. 使用 `implement` 技能按垂直切片实现；每片完成后验证核心路径并更新任务进度。
4. 使用 `code-review` 技能先运行现有测试，再审查正确性、边界、安全、性能与可维护性；存在必须修复项则回到第 3 步。

调用同目录的对应技能以遵循其完整方法与输出规则。
